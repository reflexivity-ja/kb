# Reflexivity ユースケース

Reflexivityの実例を、**運用者別**または**運用資産別**の2つの入口からご覧いただけます。

## 運用者別

[誰が使うかから探す →](運用者別/README.md)

ウェルスマネジメント / RIA、ヘッジファンド、ロングオンリー・アセットマネージャーなど、利用者や運用スタイルごとにユースケースを整理しています。

## 運用資産別

[扱う資産・市場から探す →](運用資産別/README.md)

株式、債券、FX、マルチアセット、マクロなど、実際の調査で扱う資産・市場ごとにユースケースを整理しています。同じユースケースが複数の運用者タイプや資産クラスに関係する場合も、本文を複製せず、それぞれの入口から同じページへ案内します。

> 掲載している数値や市場環境は、それぞれの調査・提供日時点のものです。現在の投資判断に使う場合は最新データとあわせて確認してください。

## 提供元

Reflexivityが作成した調査事例に加え、パートナーから提供された活用例も掲載しています。

**株式会社QUICK提供**のページには、各ページの冒頭に著者と提供日を明記しています。元のメールに含まれる顧客名、宛先、メールアドレス、署名などは除きつつ、質問、分析の流れ、図表、結論はできる限り元資料のストーリーを保って掲載しています。

## 出典・元資料

既存のユースケースコレクションは **Reflexivity Insights Proof Set - Sales Enablement.docx**（2026-09-07提供）、Reflexivity上で生成された追加の調査事例、およびパートナー提供の活用例をもとに整理しています。
