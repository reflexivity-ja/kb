# Reflexivity ユースケース

Reflexivity の実例を、**運用者別**または**運用資産別**の2つの入口からご覧いただけます。

## 運用者別

[誰が使うかから探す →](運用者別/README.md)

ウェルスマネジメント / RIA、ヘッジファンド、ロングオンリー・アセットマネージャーなど、利用者・運用スタイルごとにユースケースを整理しています。

## 運用資産別

[扱う資産・市場から探す →](運用資産別/README.md)

株式、債券、FX、マルチアセット、マクロなど、実際の調査で使用する資産・市場ごとにユースケースを整理しています。

同じユースケースが複数の運用者タイプや資産クラスに関係する場合は、記事を複製せず、それぞれの入口から同じ記事へクロス参照します。

> 以下は日付時点のプラットフォーム出力をもとにした例です。利用時には最新の市場データと照合するか、説明用の事例としてご利用ください。

## 提供元

ユースケースにはReflexivityが整理した例に加え、パートナーから提供された活用例も掲載しています。

**株式会社QUICK提供**のページには、各記事の冒頭に **提供: 株式会社QUICK** と **提供日** を明記しています。元のメール本文、送受信者情報、顧客名、署名等は公開せず、活用例の内容だけを公開用に再構成しています。
