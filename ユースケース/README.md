# Reflexivity ユースケース

Reflexivity の実例を、**ペルソナ別**、**インサイトタイプ別**、または**運用資産別**にご覧いただけます。

個別記事では、元のresearchを開かなくても、**どのような問いを調査できるか、どの資産クラスやデータを使うか、どのようなアウトプットが得られるか**が分かるように整理しています。

> 以下は日付時点のプラットフォーム出力をもとにした例です。利用時には最新の市場データと照合するか、説明用の事例としてご利用ください。

## 運用資産別

[債券・FX・株式・マクロ／クロスアセット・クオンツのユースケースを見る →](運用資産別/README.md)
