# 運用資産別ユースケース

Reflexivityでどのような調査・分析ができるかを、**実際に分析で使用する運用資産・市場**から探せます。

同じユースケースが複数の資産クラスにまたがる場合があります。記事自体は主たる資産クラスに一度だけ保存し、関連する資産ページからクロス参照します。

## 資産クラス

- [株式](株式/)
- [債券](債券/)
- [FX](FX/)
- [マルチアセット](マルチアセット/)
- [マクロ](マクロ/)

### クロス参照で扱うその他の資産

コモディティ、暗号資産については、現時点では独立した物理フォルダを増やさず、該当する株式・FX・マルチアセット・マクロのユースケースからクロス参照します。

## QUICK提供コンテンツについて

QUICK提供のユースケースには、各ページに以下を明記しています。

- **提供:** 株式会社QUICK
- **提供日:** QUICKから共有された日付
- 関連する運用資産
- 想定利用者

元のメールそのもの、送受信者情報、顧客名、署名等は公開せず、QUICKから共有されたReflexivity活用例の内容だけを公開用に再構成しています。
