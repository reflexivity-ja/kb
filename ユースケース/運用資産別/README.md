# 運用資産別ユースケース

Reflexivityでどのような調査・分析ができるかを、**実際に分析で使用する運用資産・市場**から探せます。

各ページは元のresearchを開かなくても、**どのような問いを調査できるか、どの資産クラスを使うか、どのようなアウトプットが得られるか**が分かるように整理しています。

一つのユースケースが複数の資産クラスにまたがる場合があります。その場合も記事を複製せず、同じユースケースを複数の入口から参照します。

> 以下は特定時点のプラットフォーム出力をもとにした説明用の事例です。実際の投資判断では最新の市場データと各記事に記載した制約をご確認ください。

## 債券

- [フランス国債の信用不安から相対価値トレードを構築する](../ケース/french-sovereign-corporate-yield-inversion-trade-ideas.md)  
  フランス、ドイツ、イタリア、ギリシャ等の国債、企業社債、カーブを比較し、国債間・国債対社債・FX等の相対価値トレード候補へ展開します。

- [米国イールドカーブからスティープナー／フラットナー候補をスクリーニングする](../ケース/us-yield-curve-relative-value-screen.md)  
  米国債の複数年限を歴史的なスプレッド分布とキャリー／ロールダウンで比較し、カーブ上の候補を抽出します。

- [2年・10年金利差は本当に景気後退を予測できるか検証する](../ケース/us-2s10s-recession-signal-validation.md)  
  イールドカーブ逆転という市場の経験則を長期時系列で検証し、予測精度、誤検知、リードタイムを確認します。

- [債券市場の動きが株式の先行リターンと関係するか検証する](../ケース/bond-signals-vs-forward-equity-returns.md)  
  債券側の市場シグナルとその後の株式リターンを同じ時系列上で比較し、クロスアセットの先行性を検証します。

## FX

- [EUR/USDの投資判断を体系的なチェックリストに落とし込む](../ケース/eurusd-systematic-investment-checklist.md)  
  ポジショニング、PMI、雇用、インフレ、金利差、実質金利、中央銀行、バリュエーション、ボラティリティ、テクニカルを一つの投資判断プロセスとして更新します。

- [EUR/USDのRSI戦略をパラメータ別・アウトオブサンプルで検証する](../ケース/eurusd-rsi-walk-forward-backtest.md)  
  RSI戦略を複数パラメータ、取引コスト、walk-forward splitで比較し、過剰適合とout-of-sample robustnessを検証します。

- [フランス国債の信用不安から相対価値トレードを構築する](../ケース/french-sovereign-corporate-yield-inversion-trade-ideas.md)  
  欧州のソブリンリスクをEUR等の別市場で表現できるかまで比較するクロスアセット例です。
