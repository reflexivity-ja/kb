# EUR/USDの投資判断を体系的なチェックリストに落とし込む

**主な運用資産:** FX（EUR/USD）  
**想定利用者:** FX PM、マクロPM、マルチアセット運用者  
**分析タイプ:** マクロ分析、投資判断、シナリオ分析

> 以下は特定時点のプラットフォーム出力をもとにした説明用の事例です。実際の投資判断では最新の市場データをご確認ください。

## どのような業務に使えるか

FXの判断では、一つの経済指標だけではなく、ポジショニング、景況感、雇用、インフレ、金利差、実質金利、中央銀行、バリュエーション、ボラティリティ、テクニカルなど多数の要因を継続的に確認します。

この例では「EUR/USDについて調べる」という曖昧な依頼ではなく、運用者が普段使っている投資判断プロセスそのものをチェックリストとして定義し、各項目を一度に更新・比較しています。

## Reflexivityでの進め方

1. 市場ポジショニングとセンチメントを確認します。
2. 米国とユーロ圏のPMI、雇用、インフレ等を比較します。
3. 名目金利差と実質金利差を確認します。
4. 過去の関係性や回帰を使って現在の為替水準を評価します。
5. 中央銀行の政策スタンスと今後のイベントを整理します。
6. ボラティリティやテクニカルを加え、短期的なエントリーリスクを確認します。
7. Bull / Base / Bearのシナリオに分け、条件と想定方向を整理します。

## 得られるアウトプットのイメージ

- EUR/USDを動かす主要ファクターの一覧と現在の方向性
- 米欧のマクロ・金利差比較
- ポジショニングやバリュエーションの過熱／割安評価
- 今後注目すべき経済指標・中央銀行イベント
- Bull / Base / Bearシナリオと、それぞれを成立させる条件

## この例のポイント

毎回ゼロから調査項目を考えるのではなく、**自分の投資プロセスを再利用可能な調査テンプレートとしてReflexivityに渡す**ことができます。日次・週次の市場チェックや、投資委員会前の更新作業にも応用できます。
